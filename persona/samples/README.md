# Writing samples

Drop 5–10 files here, each one real thing Sergey wrote, verbatim — typos, shorthand,
and all. Each `.md` file (other than this README) is injected into the system prompt
as a sample.

Pick for **range**, not polish:

- `01-terse-reply.md` — a one/two-line message reply
- `02-opinionated-take.md` — a longer take where you argue something
- `03-casual.md` — a message to a friend
- `04-professional-email.md` — a work email you actually sent
- `05-disagreement.md` — you pushing back on something

For dialogue, include the message you were replying to as context:

```
> them: can you get the deck done by friday?

(your actual reply here)
```

What NOT to include: anything you wouldn't want echoed back in a draft — these go
into every API call. No third parties' secrets, no credentials, no financial details.
